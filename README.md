# ❄️ Frosty

**Frosty** – это легкое и красивое desktop-приложение для Windows, которое запускает реалистичную интерактивную симуляцию падающего снега прямо поверх вашего рабочего стола и окон. 

Приложение работает в фоновом режиме, не нагружает систему, управляется через трей и создает уютную зимнюю атмосферу, никак не мешая вам работать, играть или серфить в интернете.

## 🚀 Основные возможности

- **Интерактивная физика снега** – снежинки реагируют на движение мыши и преграды.
- **Нативная работа поверх окон** – оверлей аккуратно встраивается в систему, не мешая вашим задачам.
- **Гибкие настройки** – удобное меню для управления скоростью, интенсивностью снегопада и параметрами отображения.
- **Системный трей** – сворачивается в трей и не захламляет панель задач.
- **Высокая производительность** – написан на C# / WPF (.NET 10), работает быстро и потребляет минимум ресурсов.

## 📥 Скачать и установить

1. Перейдите в раздел **[Releases](https://github.com/mls4ekui/Frosty/releases)**.
2. Скачайте готовый исполняемый файл **`Frosty.exe`** из последней версии.
3. Запустите его – установка не требуется (Portable-формат).
